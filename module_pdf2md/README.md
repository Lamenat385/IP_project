# docconvert

Утилита командной строки, которая при помощи [docling](https://github.com/docling-project/docling)
преобразует PDF-документы (учебники, научные работы, техническую документацию) в
**один очищенный текстовый файл** (`.md` или `.txt`).

Поддерживается OCR для сканированных книг, распознавание формул в LaTeX, работа
на GPU, кэширование и гибкая очистка от «мусора» (колонтитулы, номера страниц,
битые переносы, пустые строки, списки литературы).

## Строение

### Структура проекта

```
module_pdf2md/
├── docconvert.cmd              # обёртка для Windows: запуск без активации venv
├── pyproject.toml              # метаданные пакета, зависимости, entry point
├── README.md
├── docs/                       # исходные PDF (по умолчанию)
├── .venv/                      # виртуальное окружение (docling, torch, ...)
└── source/
    └── docconvert/
        ├── __init__.py         # версия пакета
        ├── __main__.py         # python -m docconvert
        ├── cli.py              # разбор аргументов, оркестрация, сборка файла
        ├── converter.py        # обёртка над docling: OCR, формулы, кэш
        └── cleanup.py          # правила очистки документа и текста
```

Пакет устанавливается в режиме editable (`pip install -e .`), поэтому правки в
`source/docconvert/` применяются сразу, без переустановки.

### Как это работает (поток данных)

```
  CLI (cli.py)
      │
      ├─ find_documents()        собрать .pdf из папок/файлов
      │
      ├─ build_converter()       настроить docling (device, OCR, таблицы)
      │
      └─ для каждого PDF:
             convert_file()      конвертация (или загрузка из кэша)
                   │  → DoclingDocument
                   ▼
             clean_document()    удаление колонтитулов/повторов/TOC из модели
                   │
             export_to_markdown()/export_to_text()
                   │  → сырой текст
                   ▼
             clean_text()        дегифенация, мусор, пробелы, литература
                   │  → очищенный текст
                   ▼
        _build_section() + сборка всех документов → один output-файл
```

Ключевая идея: очистка выполняется в **два уровня** — сначала на уровне модели
документа (`clean_document`, есть координаты и метки блоков), затем на уровне
готового текста (`clean_text`, обычные строки).

### Модули

#### `cli.py`
- `build_parser()` — описание всех флагов командной строки.
- `main()` — главный сценарий: находит документы, строит конвертер, по очереди
  конвертирует и очищает каждый файл, собирает результат в один файл.
- `_parse_pages()` — разбор `--pages 1-20` / `--pages 5`.
- `_build_section()` — оформление блока одного документа (заголовок + имя источника).
- Ошибка на одном документе не прерывает обработку остальных (см. `cli.py:239`).

#### `converter.py`
- `ConvertOptions` — датакласс настроек конвертации (OCR, движок, языки, таблицы,
  распознавание формул, диапазон страниц, устройство, кэш).
- `build_converter()` — создаёт `DocumentConverter` docling с нужным pipeline:
  - `AcceleratorDevice` (`cpu`/`cuda`),
  - движок OCR и языки,
  - распознавание таблиц вкл/выкл,
  - распознавание формул (`do_formula_enrichment`) вкл/выкл.
- `resolve_device()` / `torch_cuda_available()` — выбор `cuda` при наличии, иначе
  `cpu`, с предупреждением при явном запросе недоступного GPU.
- `convert_file()` — конвертация одного PDF с опциональным JSON-кэшем.
- `find_documents()` — раскрытие папок в отсортированный список PDF (уникальные пути).

#### `cleanup.py`
- `CleanupOptions` — какие правила применять и параметры подбора повторов.
- `clean_document()` — удаление из модели: слой `furniture` (колонтитулы), повторов
  у краёв страниц, оглавления (TOC). Возвращает `CleanupStats`.
- `clean_text()` — постобработка готового текста (дегифенация, номера страниц,
  строки-шум, плейсхолдеры docling, схлопывание пробелов, обрезка списка литературы,
  починка математических символов и чистка распознанных формул).
- `_repair_symbols()` — восстановление нерасшифрованных глифов (`≠`, `′`, `□`,
  `—`, `«»`) и HTML-сущностей.
- `_sanitize_formulas()` — удаление из LaTeX-формул «зацикливаний» декодера,
  `\intertext` и транслитерированной кириллицы, которую модель иногда дописывает.
- `CleanupStats` — счётчики удалённого и `summary()` для лога.

### Правила очистки

| Правило | Что делает | Отключить флагом |
|---|---|---|
| Колонтитулы (`furniture`) | удаляет верхний/нижний колонтитул из слоя furniture | `--keep-headers-footers` |
| Повторяющиеся строки | удаляет короткие строки, повторяющиеся у краёв многих страниц | `--keep-repeated-lines` |
| Оглавление | удаляет блок `document_index` (TOC) | включается `--drop-toc` |
| Номера страниц | удаляет строки-числа и римские цифры | `--keep-page-numbers` |
| Строки-шум | удаляет строки из одной пунктуации | `--keep-noise` |
| Плейсхолдеры | удаляет `<!-- formula-not-decoded -->` и т. п. | `--no-clean` |
| Дегифенация | склеивает слова, разорванные переносом (`пред-\nложение` → `предложение`) | `--no-dehyphenate` |
| Пробелы | схлопывает повторные пробелы и пустые строки | `--no-collapse` |
| Список литературы | обрезает всё от заголовка References/Литература/Библиография | `--keep-references` |
| Символы | восстанавливает `≠`, `′`, `□`, `—`, `«»` и HTML-сущности | `--no-fix-symbols` |
| Формулы | чистит LaTeX от зацикливаний, `\intertext` и транслита | `--no-sanitize-formulas` |

Полностью отключить всю очистку — `--no-clean`.

Подбор повторяющихся строк настраивается константами в `CleanupOptions`:
`edge_ratio` (доля высоты страницы у края), `repeat_min_pages`,
`repeat_min_ratio`, `max_header_len`.

### Куда сохраняются файлы

- **Итоговый файл** — путь из `-o/--output`; если не задан, то `converted.md`
  (или `converted.txt` при `--format txt`) в **текущей рабочей папке**.
- **`--split`** — дополнительно пишет по одному файлу на документ в папку
  итогового файла (имя = `<имя_pdf>.<md|txt>`).
- **`--cache-dir`** — JSON-кэш конвертаций (не текстовый вывод).
- Модели docling кэшируются в `%USERPROFILE%\.cache\huggingface\hub`.

## Использование

### Установка

```powershell
# 1. виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. зависимости (docling подтянет torch и модели)
pip install -e .

# 3. опционально: движок OCR EasyOCR (лучше для русского)
pip install -e ".[easyocr]"
```

Проверка установки:

```powershell
docconvert --version
# или без активации venv:
.\docconvert.cmd --version
```

### Быстрый старт

```powershell
# по умолчанию: все PDF из папки docs → converted.md
.\docconvert.cmd
```

### Примеры

```powershell
# конкретная папка и файл
.\docconvert.cmd docs -o book.md

# обычный текст вместо markdown
.\docconvert.cmd docs --format txt -o book.txt

# плюс отдельный файл на каждый PDF
.\docconvert.cmd docs -o out\book.md --split

# обход вложенных папок
.\docconvert.cmd docs -r -o all.md

# заголовок в начале итогового файла
.\docconvert.cmd docs -o book.md --title "Никольский, Матан Том 1"

# только диапазон страниц (быстрая проверка больших книг)
.\docconvert.cmd docs --pages 1-30 -o sample.md
.\docconvert.cmd docs --pages 40 -o page40.md

# сканированная книга: GPU + EasyOCR (русский + английский)
.\docconvert.cmd docs --device cuda --ocr always --ocr-engine easyocr `
    --ocr-lang ru --ocr-lang en -o book.md --cache-dir .docling-cache

# оставить литературу и колонтитулы, только убрать лишние пробелы
.\docconvert.cmd docs --keep-references --keep-headers-footers -o book.md
```

### Все параметры CLI

Основные:

| Параметр | Описание |
|---|---|
| `inputs ...` | PDF-файлы и/или папки. По умолчанию — папка `docs`. |
| `-o, --output` | Итоговый файл (по умолчанию `converted.md`/`converted.txt`). |
| `--format {md,txt}` | Формат вывода (по умолчанию `md`). |
| `-r, --recursive` | Искать PDF во вложенных папках. |
| `--split` | Писать отдельный файл на каждый документ. |
| `--title` | Заголовок в начале итогового файла. |
| `--pages START-END` | Только диапазон страниц (`1-20` или `5`). |
| `--cache-dir DIR` | Папка JSON-кэша конвертаций. |

OCR / извлечение:

| Параметр | Описание |
|---|---|
| `--ocr {auto,always,never}` | Режим OCR (по умолчанию `auto`). `always` — полностраничный OCR. |
| `--ocr-engine {auto,rapidocr,easyocr,tesseract}` | Движок OCR (по умолчанию `auto`). |
| `--ocr-lang CODE` | Язык OCR (можно повторять): `ru`, `en`, `cyrillic`, `ch`, `iso:ru`. |
| `--no-tables` | Отключить распознавание таблиц (быстрее). |
| `--device {auto,cpu,cuda}` | Устройство вычислений (по умолчанию `auto`). |

Математика / формулы:

| Параметр | Описание |
|---|---|
| `--formulas` | Распознавать формулы и выводить их как LaTeX (по умолчанию включено). |
| `--no-formulas` | Отключить распознавание формул (быстрее; формулы станут плейсхолдерами). |

Очистка:

| Параметр | Описание |
|---|---|
| `--no-clean` | Отключить все правила очистки. |
| `--keep-headers-footers` | Оставить колонтитулы. |
| `--keep-repeated-lines` | Оставить повторяющиеся строки. |
| `--drop-toc` | Удалить оглавление. |
| `--no-dehyphenate` | Не склеивать переносы. |
| `--keep-page-numbers` | Оставить номера страниц. |
| `--keep-noise` | Оставить строки-шум. |
| `--keep-references` | Оставить список литературы. |
| `--no-collapse` | Не схлопывать пробелы и пустые строки. |
| `--no-fix-symbols` | Не чинить `≠`, `′`, `—`, `«»` и HTML-сущности. |
| `--no-sanitize-formulas` | Не чистить распознанный LaTeX. |

Прочее:

| Параметр | Описание |
|---|---|
| `-q, --quiet` | Только предупреждения и ошибки. |
| `-v, --verbose` | Подробный (debug) лог и трейсбеки. |
| `--version` | Показать версию. |

### Математика и формулы

Учебники и статьи полны выключных формул. Без обработки docling заменяет их
плейсхолдерами `<!-- formula-not-decoded -->`, а иногда глифы (`≠`, `′`, `(`, `)`)
приходят как нерасшифрованный символ `�`. Утилита решает это на двух уровнях:

1. **Распознавание формул** (`do_formula_enrichment`, включено по умолчанию).
   Docling вырезает область формулы из страницы и прогоняет её через модель
   `docling-project/CodeFormulaV2`, получая **LaTeX**:

   ```markdown
   $$
   f ( z ) = a _ { n } z ^ { n } + a _ { n - 1 } z ^ { n - 1 } + \cdots + a _ { 1 } z + a _ { 0 } ,
   $$
   ```

   Первый запуск скачает модель в `%USERPROFILE%\.cache\huggingface\hub` и
   заметно медленнее обычного (на GPU это главный потребитель времени). Отключить
   можно флагом `--no-formulas`.

2. **Постобработка** (`cleanup.py`). Модель иногда «зацикливается» или дописывает
   транслитерированную кириллицу рядом с формулой; такие фрагменты вычищаются
   (`_sanitize_formulas`). Не расшифрованные глифы в тексте восстанавливаются по
   контексту: `≠`, `′`, `□` (конец доказательства), `—`, `«»`, а также HTML-сущности
   (`&lt;`, `&gt;`, `&amp;`) — `_repair_symbols`.

```powershell
# по умолчанию: формулы → LaTeX + починка символов
.\docconvert.cmd docs -o book.md

# без формул: быстрее, формулы останутся плейсхолдерами
.\docconvert.cmd docs --no-formulas -o book.md

# без чистки распознанного LaTeX и без починки символов
.\docconvert.cmd docs --no-sanitize-formulas --no-fix-symbols -o book.md
```

> Совет: если в исходном PDF нет текстового слоя или он битый (видны `�`),
> помогает OCR — см. следующий раздел. Для русского используйте
> `--ocr-engine easyocr --ocr-lang ru`.

### Сканированные книги и OCR

Если у PDF нормальный текстовый слой — OCR не нужен (`--ocr auto`/`never`).
Если это скан или текстовый слой битый (теряются символы), нужен OCR:

- **EasyOCR** с `--ocr-lang ru` даёт лучший результат для русского;
- **RapidOCR** быстрее, но для кириллицы слабее (использует код `cyrillic`);
- **Tesseract** требует отдельно установленного бинаря с языковыми данными.

```powershell
# скан на русском
.\docconvert.cmd docs --ocr always --ocr-engine easyocr --ocr-lang ru --ocr-lang en -o scan.md
```

> Внимание: сам движок OCR лежит в пакете `easyocr` — установите его (`pip install -e ".[easyocr]"`).

### Работа на GPU

Ускорение доступно при CUDA-сборке torch. Проверка:

```powershell
.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"
```

Если `False`, поставьте CUDA-колесо (пример для CUDA 12.6):

```powershell
pip install "torch==2.14.1+cu126" "torchvision==0.29.1+cu126" `
    --index-url https://download.pytorch.org/whl/cu126
```

Затем запускайте с `--device cuda` (или `auto` — GPU будет выбран автоматически).
Если CUDA запрошена, но недоступна, утилита предупредит и откатится на CPU.

### Кэширование

Конвертация docling тяжёлая. С `--cache-dir` результат сохраняется в JSON,
привязанный к файлу (размер, дата, содержимое) и настройкам; повторный запуск с
теми же параметрами загрузит кэш мгновенно. Удобно при итерациях по очистке:

```powershell
.\docconvert.cmd docs --cache-dir .docling-cache -o book.md
```
